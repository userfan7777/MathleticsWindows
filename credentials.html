Guardar inicio de sesión

Mathletics Desktop puede recordar tus credenciales para rellenar el formulario oficial cuando vuelva a pedirte iniciar sesión.

La contraseña se cifra con la protección de Windows para tu cuenta de usuario. No se guarda en texto plano ni se comparte con el archivo EXE. El formulario se rellenará automáticamente, pero tendrás que confirmar el inicio de sesión.
